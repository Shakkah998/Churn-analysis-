# 📈 Churn Analysis Dashboard

---

## 📌 Overview  
This project uses **Power BI dashboards** to perform a full churn analysis. It examines user / customer behavioural data to uncover churn patterns, rates, contributing factors, and trends, to help businesses retain customers and improve service offerings.

---

## 🎯 Objectives  
- Quantify churn rate and track its evolution over time.  
- Identify the key predictors of customer churn (e.g., usage, subscription type, demographics).  
- Compare churn across segments (e.g., plan types, regions).  
- Provide interactive visuals to help decision-makers understand who is leaving and why.  

---

## 📂 Data Sources  
- Internal / supplied data on customer usage, subscriptions, cancellations, plan details, and demographic info.  
- Includes multiple features: customer profile, product / plan type, usage metrics, cancellation history.

---

## 🛠 Tools & Technologies  
- **Power BI** for building dashboards and visual exploration  
- **DAX** for measure and metric calculations  
- Power Query for data cleaning & transformation  

---

## ⚙️ Methodology  
1. Data Import & Consolidation: Load all relevant customer and subscription data into Power BI.  
2. Data Cleaning: Remove missing or inconsistent records, standardize fields and categories.  
3. Exploratory Analysis: Visualize patterns in churn over time, by plan, region, usage.  
4. Data Modeling: Create relationships, calculated measures (e.g., churn rate, retention metrics) using DAX.  
5. Visualization Design: Build dashboards with filters, slicers, and segment comparisons (e.g. plan, demographics).  
6. Sharing & Feedback: Publish dashboard for stakeholders to review and provide insights.

---

- Certain plan types or customer segments have higher churn.

- Demographic or region differences in churn rates are visible (if applicable).
